MiMo 智能代码审查助手

项目背景

最近在开发一些个人项目时，经常需要手动检查代码质量，但发现传统工具要么规则太死板，要么配置太复杂。正好看到小米MiMo开放了API，就想着能不能结合大模型的能力，做一个更智能的代码审查工具。

这个项目是我利用业余时间开发的，前后大概花了三周左右。最开始只是想做个简单的命令行工具，后来觉得有个可视化界面会更方便，就加上了Web前端。

主要功能

目前实现的功能还算实用：

• 代码上传和分析：支持拖拽上传，能自动识别Python、JS/TS、Java等常见语言

• 问题检测：除了基本的语法检查，还能发现一些逻辑上的潜在问题（比如无限循环风险、未处理的异常等）

• 修复建议：针对检测到的问题，会给出具体的修改建议，有些还能直接生成修复后的代码片段


技术实现

后端用的是Flask，主要考虑是轻量、快速上手。处理流程大致是：
1. 接收前端上传的代码文件
2. 调用MiMo API进行分析（目前主要用code-review和code-explain两个端点）
3. 解析返回结果，整理成结构化的数据
4. 返回给前端展示

前端用React + TypeScript，界面比较简洁。重点做了：
• 文件上传的拖拽体验

• 问题列表的筛选和排序

• 代码编辑器的集成和问题高亮

1. MiMo API的调用限制：初期测试时频繁触发频率限制，后来加了请求队列和缓存机制
2. 大文件处理：超过1000行的代码文件，直接调用API容易超时。现在会先做代码分段，再分批处理
3. 结果解析：MiMo返回的文本需要解析成结构化的数据，用了正则+关键词匹配的方式，还在优化中

如何运行

Windows用户可以直接运行start.bat，Linux/Mac用start.sh。脚本会：
1. 检查Python和Node环境
2. 安装依赖（后端用pip，前端用npm）
3. 启动Flask后端（默认5000端口）
4. 启动React前端（默认5173端口）

第一次运行需要配置MiMo的API密钥，在backend/.env文件里设置。
